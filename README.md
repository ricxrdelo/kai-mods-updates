# KAI Mods — обновления

Отсюда программа **KAI Mods** (хитмаркер и счётчик урона для GTA V Legacy / RAGE MP) сама скачивает свои обновления.

- Последняя версия: [Releases → Latest](https://github.com/ricxrdelo/kai-mods-updates/releases/latest) — файл `KaiMods.exe`.
- Каждый выпуск подписан ключом автора (`update.json.sig`). Программа ставит обновление, только если подпись и контрольная сумма сходятся.

Исходного кода здесь нет — только выпуски программы.
